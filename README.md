An early world-news front page for Monday, 23 November 2026. The paper uses Astryx Stone Light regional inks, original spot illustrations, and fixed Newsreader and Source Sans 3 type masks under the licenses in `fonts/`.

```sh
MAKEFUN_OUTPUT_DIR=./preview python3 -P -s main.py
```

The Python 3.13 renderer uses the standard library and runs offline. When `MAKEFUN_OUTPUT_DIR` is unset, it writes `/output/entry.png`. Story notes, dates and source links are in `edition.json`.
